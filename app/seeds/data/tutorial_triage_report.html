Invented sample data bundled with this tutorial. No row describes a real filing, client, firm or commitment.

Beside each filing sits what the same client said in public, where a commitment was on record. A filing is marked when it asks government for the opposite of that commitment — and where it is marked, both texts are printed together, so the contradiction is on the page rather than only in the flag. It is a reading aid, not a verdict, and not a finding about the filer. Every row carries a Show the work link back through each stage that touched it to the input row it came from. Those links are served by the app that produced this page; in a copy of this file opened on its own they will not resolve.
