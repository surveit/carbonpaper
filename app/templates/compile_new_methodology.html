New project · paste methodology → data model → workflow

Paste a methodology write-up (how an investigation finds, verifies, and surfaces its claims). This page creates the project and generates its data model — the named schemas the pipeline needs — and STOPS for your approval. The workflow is then authored stage by stage from an MCP client (see below); each stage is validated against the whole graph as it is added, and you review, approve and version every stage here. Everything lands in a new examples/<name>/ working copy with the full review / version / run UI.

Author from your own AI

The workflow is authored from an MCP client. Connect Claude Code (or any other MCP client) to this server and it creates the project, agrees its words with you, and writes the stages one at a time, each validated against the whole graph before it is stored. You still review, approve and version every stage here.

claude mcp add --transport http carbon_paper {{ request.base_url }}mcp

Then start with a prompt like this (copy it):

I want to turn an investigation methodology into a reviewable data pipeline using the "carbon_paper" MCP server. Interview me about the investigation first, then write the methodology document and call create_project. Next agree the project's words with me — the nouns and verbs the methodology already uses — and store them with write_terms before any stage is written. Then author the workflow one stage at a time in dependency order — read_stage each upstream stage first so a new stage's declared input schema matches what that stage actually outputs, then add_stage the full stage. If an add comes back with issues, read the upstream it names, fix the stage and add it again. Show me read_workflow_summary as the graph grows, and tell me when the draft is complete so I can review and approve the stages here.
