It borrows `.stage-cert`'s markup because it makes the same KIND of claim as the certification badge and must be read with the same suspicion — but the claim differs, and the wording carries the difference. Certification asks whether a step's description matches its code. This asks whether its output matches rows a person labelled by hand. For an llm_transform there is no certification badge at all (no authored code block), so this is the only thing that can vouch for the step a reader most needs to trust. Nothing is rendered for a step no eval targets.
