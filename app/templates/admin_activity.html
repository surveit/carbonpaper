Instance activity

Is anyone using this instance, and how far do they get before they stop? Counted off the records this app already writes in the course of doing its job — project records, working copies, stored workflow versions, uploaded files and run manifests. None of it comes from tracking, because there is none: nothing in this app records a visit, a request, a browser or a person.

What these records cannot say

Each of these is unknown, not zero. No figure below estimates any of them, and none of them has a denominator these records hold.

How many people arrived
Nothing records a visit or a request. Someone who opened this instance and left wrote nothing down, so the funnel below has no top: it starts at the first act that stores a record. How many arrivals become a project is not a number this app can produce.
How many people these are
No record carries an identity. The projects counted below could be one person or as many people as there are projects. A version's reviewer is free text whoever saved it supplied, not someone this app authenticated.
Whether anyone took the guided tour
The tour's "already started" flag lives in the visitor's own browser storage and never reaches the server. Tour starts, how far they got and where they gave up are all invisible here.
Whether a finished run reached a reader
Exporting a run as a review packet writes no record, and neither does downloading a file a run published. The last step of the funnel — the work leaving this instance and going to someone — cannot be counted today.
Whether a quiet project was abandoned
A project with no run may have been given up on, or exported and finished somewhere else. These records say only that nothing further happened here.
When someone actually started
created_at is when the record was written, not when the work began. A project imported from a bundle is stamped at import.
How many projects there have ever been
The project count is a floor, not a total. A project marked private, and a project deleted out of the workspace, are both left out of every figure on this page — the one listing this page is allowed to read drops them, and counting them would be a listing of them. Someone who built a project and then deleted it is invisible here, and their runs fall into the count below.
Whether a run with no ending is still going
A run whose process died writes no terminal status, so it reads the same as one still executing. The running figure below mixes the two and this page will not guess the split.
