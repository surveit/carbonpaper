# Running an eval item

One row per case. An eval item carries the case's source files, the shape an answer should
take, and what the artifact expects. Nothing here reads a web page: the item was generated by
a separate run and is a fixed thing this can be re-run against.

`resolve_sources` turns the case's checkout-relative source paths into paths on this machine. A
path that is missing, that is absolute, or that resolves outside the checkout raises, which
fails the stage and so the whole run.

`blind_build` renders into its prompt only the columns it reads — the source paths and the
answer's shape — and the loader refuses a prompt that names any other column. So the expected
answers flow past the build unread, and `blind_build` hands back a run, not figures. Its
pipeline's last stage must be `answer` and write one row in the shape asked for. A build that
cannot get there returns no run and says what stopped it, which is a result rather than a
failure to report.

`verify_citation` asks the workspace whether the cited run finished; a run that errored has no
answer to read, whatever files it left behind. `read_answer` then reads the figures out of
that run's `answer` stage.

`compare` grades each figure, type first: the schema declares a type, so a value of the wrong
type is graded `wrong_type` rather than compared — an integer field answered with a date is a
failure of the build, not a disagreement about a number. A wrong-typed figure is not resolved
here; it is left to the judge like any other disagreement. A value of the right type is then
checked against what the artifact states. A case whose `expected_json` or `target_schema` is
empty, or whose `expected_json` lists no figures, raises: it is bad case data, not a case to grade.

`diagnose` rules on each disagreement the comparison found — our defect, their defect, genuine
ambiguity, or consistent with hedged wording the rebuild's exact value satisfies.

`verdict` fails the case, with a stated reason, at the first of: the citation did not hold; the
judge did not trust the comparison; its diagnosis could not be read as a JSON list; a ruling is
not an object with a text field and a text verdict, or names a verdict or a field the comparison
does not carry; a disagreeing figure got no ruling at all; or a ruling is our own defect. It
passes otherwise.

`claims` turns a figure into a claim in the page's own words, on the run that was graded, and
waits for its review, two at a time. A figure is claimed when the rebuild wrote a value for it,
the page's words for it are recorded, no ruling for it says our defect, and either `compare`
graded it `agrees` or the diagnosis holds exactly one ruling for it that says their defect,
genuine ambiguity or consistent. Any other figure is skipped, with its reason recorded: ruled our
defect, left unruled, a ruling that cannot be read (a missing, unknown or non-text verdict, or two
rulings on one figure), no rebuilt value, no recorded quote, or a quote for a figure the rebuild
never answered. If the diagnosis as a whole cannot be read as a JSON list, only `agrees` figures
are claimed. When the citation did not hold or the judge did not trust the comparison, it makes no
calls at all. An
eval run never reaches it — previewing or stage-testing it submits real claims.
